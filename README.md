# 简单定居游牧共存 （SSNC）

## 简介

- 这是一个群星模组，对初始选择为定居的帝国做了简单适配，使其可在定居的同时可以操控方舟舰
  - 由于基于定居进行修改，游牧的运行储备局势将不存在，其增益移至游牧传统树
- 本模组依赖 Nomads DLC

## 内容

- 一个国民理念 --- 方舟传承
  - 非游牧帝国可选
  - 开局获得一艘科研方舟，停靠于首都星系
- 一个游牧传统树
  - 提供游牧的相关科技研究选项
  - 提供游牧运行储备局势的增益
  - 若帝国没有国民理念 --- 方舟传承，采纳游牧传统树时会开启局势--方舟建造工程，当局势结束时，会在帝国首都星系创建一艘方舟舰

## 注意事项

- 本模组制作者能力和精力有限，不能进行详尽的测试，如果发现任何问题，请提交Issues
- 本模组修改了方舟舰、驿站相关科技以及后勤舰，修改了部分原版游牧机制，不建议与同样定位的模组同时加载
- 本模组正在适配游牧合约中
