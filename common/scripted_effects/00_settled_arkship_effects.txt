# 深度睡眠帝国的新殖民地补 3 个冷冻舱（星球/方舟通用；已有冷冻舱则跳过）
settled_arkship_add_deep_sleep_cryo_pods_effect = {
	if = {
		limit = {
			owner = {
				is_deep_sleep_country = yes
			}
			NOR = {
				has_deposit = d_deep_sleep_cryo_pods
				has_deposit = d_deep_sleep_cryo_pods_renewed
			}
		}
		while = {
			count < 3
			add_deposit = d_deep_sleep_cryo_pods
		}
	}
}

# 定居帝国从单个星球殖民地登上方舟（拦截原版登舰启航）
# $ARKSHIP_TYPE$ = science / civilian / military
# $EMBARKED_PLANET$ = 被登舰的殖民地
settled_arkship_embark_colony_effect = {
	give_technology = { tech = tech_$ARKSHIP_TYPE$_arkship message = no }
	give_technology = { tech = tech_waystation_1 message = no }
	refresh_auto_generated_ship_designs = yes
	$EMBARKED_PLANET$ = {
		save_event_target_as = settled_arkship_embark_planet
	}
	create_fleet = {
		effect = {
			set_owner = prev
			create_ship = {
				name = event_target:settled_arkship_embark_planet
				create_colony = no
				random_existing_design = $ARKSHIP_TYPE$_arkship_tier_1 # 从已有设计里选择对应的一级方舟设计
				effect = {
					save_event_target_as = settled_arkship_embarked# 保存新舰船
					initialize_arkship_starbase_effect = yes
					switch = {
						trigger = is_ship_size
						civilian_arkship_tier_1 = {
							set_graphical_culture = civilian_arkship
						}
						science_arkship_tier_1 = {
							set_graphical_culture = science_arkship
						}
						military_arkship_tier_1 = {
							set_graphical_culture = military_arkship
						}
					}
				}
			}
			set_location = {
				target = $EMBARKED_PLANET$
				distance = 0
				angle = random
			}
		}
	}
	event_target:settled_arkship_embarked = {
		transfer_carrier = {
			source = $EMBARKED_PLANET$
			target = this
			transfer_ownership = no
			merge_pops = no
			destroy_colony = yes
		}
		colony = {
			set_name = event_target:settled_arkship_embark_planet
		}
		fleet = {
			set_name = event_target:settled_arkship_embark_planet
		}
	}
	$EMBARKED_PLANET$ = {
		add_modifier = {
			modifier = stripped_planet
		}
		add_planet_devastation = 90
	}
}

# 定居方舟初始殖民地模板
# 固定区划上限 10，1 个方舟甲板和 2+1 个居住甲板（初始化还会增加一个居住甲板），甲板 zone 留空，4800 主体人口
settled_arkship_initial_colony_effect = {
	set_planet_size = 10
	add_district = {
		district_type = district_ark_basic
		ignore_cap = yes
	}
	add_district = {
		district_type = district_ark_city
		ignore_cap = yes
	}
	add_district = {
		district_type = district_ark_city
		ignore_cap = yes
	}
	while = {
		limit = { pop_amount < 4800 }
		create_pop_group = {
			species = owner_main_species
		}
	}
	# 生体荒野补二级荒野首都
	if = {
		limit = {
			owner = {
				is_wilderness_empire = yes
			}
			NOR = {
				has_building = building_colony_shelter_wilderness
				has_building = building_capital_wilderness
				has_building = building_major_capital_wilderness
				has_building = building_system_capital_wilderness
				has_building = building_imperial_capital_wilderness
			}
		}
		add_building = building_capital_wilderness
	}
	settled_arkship_origin_fixes_effect = yes
	settled_arkship_add_deep_sleep_cryo_pods_effect = yes
}

# 创建科研方舟（带初始殖民地）：逐星局势调用
create_settled_arkship_effect = {
	capital_scope = {
		save_event_target_as = settled_arkship_capital
	}
	create_fleet = {
		name = NAME_SETTLED_ARKSHIP
		effect = {
			set_owner = prev
			create_ship = {
				name = NAME_SETTLED_ARKSHIP
				design = "SETTLED_ARKSHIP_DESIGN"
				effect = {
					initialize_arkship_starbase_effect = yes
					set_graphical_culture = science_arkship
					owner = {
						create_leader = {
							class = commander
							name = random
							species = owner_main_species
							randomize_traits = no
							traits = {
								1 = random_common
							}
						}
					}
					fleet = {
						set_leader = last_created_leader
					}
					colony = {
						settled_arkship_initial_colony_effect = yes
					}
				}
			}
			set_location = {
				target = event_target:settled_arkship_capital
				distance = 0
				angle = random
			}
		}
	}
}
